## 2. 每次正式测试的证据包

```text
runs/<run_id>/
  run_manifest.json
  predictions.jsonl
  errors.jsonl
  metrics.json
  metrics_by_language.csv
  latency.csv
  hardware.json
  failure_cases.csv
  report.md
  evidence_index.json
  screenshots/
```

截图应能追溯run_id、数据集版本和sha256、模型版本、GPU/驱动、执行时间、git提交、评分规则版本和metrics哈希。允许保护隐私而打码，不能更改数值；原始音频/声纹和未公开Gold必须受控。

## 3. 截图清单

1. 系统模块化流水线架构图（DESIGN）。
2. 标注及测试数据统计界面，人工金标准与复核记录（LOCAL）。
3. 多语种流式语音识别输出画面及延迟记录（LOCAL）。
4. 每种合同语言CER/WER、S/D/I/N、样本/说话人计数与CI（ACCEPTANCE）。
5. 自主TTS和授权声音克隆效果、MOS/SIM评分与授权记录（LOCAL）。
6. 三重内容核查的事实级证据、冲突、证据不足拒播（LOCAL）。
7. GPU峰值显存、RTF、P95及不同并发的真实仪表板（LOCAL）。
8. API文档、鉴权失败、限流429和第三方联调成功记录（LOCAL）。
9. 上游模型官方基准网页**原始截图**、URL、检索日期及测试环境（PUBLIC）。

## 4. 标书提交前自检

- [ ] 所有官方基准有可访问来源、模型及数据集版本，不用自绘表冒充原始截图。
- [ ] 每种合同语言均有测试Gold、识别预测和WER/CER公式的可复算结果。
- [ ] 明确噪声、麦克风、口音、文本归一化、样本分母、无输出处理规则。
- [ ] 音色合法授权，可撤销且不泄露真人录音；语音自然度与音色相似分开计量。
- [ ] 三重核查在证据不足/服务失败情况下禁止播报确定事实。
- [ ] 实测机型、CPU/RAM/GPU/驱动、P95/并发和失败率有统一环境证据。
- [ ] 完整接口参数、授权、限流、字段及联调承诺与测试结果一致。
- [ ] 任何NOT_RUN/INCOMPLETE结果不显示为PASS；机密信息不进入公开Git。
