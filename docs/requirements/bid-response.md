# 招标语音专项范围及逐项技术响应

## 招标条款原文

> 4、数据中台与数智引擎：个性化语音合成与声音克隆模型、AI生成内容安全审核与事实核查模型（三重核查机制）、多语种语音交互引擎（识别准确率≥95%）。
>
> 5、数据中台与数智引擎：支持多国语言的实时语音识别、转写、合成与智能讲解，识别准确率≥95%，提供评测方案与基准测试数据得0.5分。
>
> 6、接口与数据互通能力：提供完整接口技术指标（通信协议、数据格式、鉴权方式、请求频率限制、字段定义），承诺开放通信协议与数据接口、配合集成联调、不设技术壁垒等条件得2分。每有一项不满足扣0.5分，扣完为止。

**范围限定**：仅响应语音相关部分；不将整个数据中台的非语音承诺归入VIS。

## 投标写法边界

1. ≥95%属于**项目验收目标**，不是已运行成绩；合同须明确语言、音频环境、归一化规则和每语种样本量。
2. 公开模型成绩不可以写成“VIS实测”；若模型在复杂环境未达到目标须真实记录。
3. 第三方模型权重、商业源码、未获得授权的数据不属于开放承诺。
4. 无本地GPU吞吐、P95、服务并发实测之前不得将10并发规划值写成设备实测容量。
5. 未有真实截图时以设计图、公开来源链接和取证计划表达，不制作伪现场证据。

## 建议技术响应

拟建设模块化多语种语音识别、转写、合成与智能讲解系统，配置授权声音克隆及三重内容审核，提供自主数据集、公开模型基准与可复现评测体系。识别准确率≥95%作为约定条件下逐语种验收目标，采用明确定义的CER/WER计算方法。提供开放接口标准、字段字典、鉴权、限流、示例及集成联调支持。
