# 测评指标计算规则与验收方案

> 设计规范V1。指标目标并非本项目已验证成绩。正式语种和语料条件应在M0冻结。

## 1. ASR基础评分

不同语言统一保留原始Reference和Hypothesis，执行相同、事前固定的归一化：Unicode、大小写、空白、标点、数字、日期、简繁和分词器版本。不得通过删除真实错误、实体或数字优化成绩。

- **WER = (S + D + I) / N_word**
- **CER = (S_char + D_char + I_char) / N_char**
- 按合同定义的“识别准确率” = (1 − WER或CER) × 100%；这是编辑距离意义的正确率，不是整句完全正确概率，极端情况可为负值。
- **整句正确率** = 完全一致的有效句数 / 有效句数。
- **LID accuracy** = 正确识别语种的有效片段数 / 有效片段数。
- **专有实体正确率** = 匹配的标注实体数 / 标注实体总数，归一化和重复规则需冻结。

S/D/I依次为替换/删除/插入，N为参考文本长度。微平均：**逐条算编辑次数，所有S/D/I加总，再除以所有参考词/字符总数**，不能简单平均句级百分数。

例如参考字符1000，替换20、删除15、插入10，CER=45/1000=4.5%，编辑距离正确率=95.5%。

中文初步采用CER，英文WER；日语、韩语按事先约定字符或固定分词器，不能在结果产生后选择较低指标。每种合同语种分别判断CER/WER≤5%，不以语种总体平均掩盖不达标语言。

若参考文本为空、静音、幻觉或模型输出缺失，应根据预先发布的特殊样本规则分类，不得除零；模型OOM、超时、音频处理错误不可悄悄剔除。

## 2. 置信区间和统计报告

报告每种语言的总样本数、参考字/词数、说话人数、音频小时、失败/排除数量、环境与口音分组，保存S、D、I、N原始计数。

同一说话人的录音相关性较强，建议按speaker聚类Bootstrap≥2000次估计95%置信区间。可用内部强化门槛“95% CI上界≤5%”，但不能未经采购方确认擅自替换正式合同规则。不要假定字符错误独立同分布。

## 3. TTS与声音克隆指标

| 指标 | 公式/方法 | 判定限制 |
|---|---|---|
| 内容一致性 | 固定独立ASR对合成语音转写后的CER/WER | 明确独立ASR误差 |
| MOS自然度 | 有效1–5分盲评得分总和/有效评分数 | 正式样本建议每条≥5名评分者，报CI |
| SIM音色相似 | 固定speaker embedding余弦相似度u·v/(||u||||v||) | 不同编码器不得横比，不是相似概率 |
| ABX听辨 | 盲测被试在匹配/对照音色中的正确选择率 | 受控音量与随机顺序 |
| TTFA | 请求被接受到首个**可播放**音频块 | P50/P95/P99 |
| TTS RTF | 合成处理时间/输出音频时长 | 指明设备、精度和批大小 |

使用3s/5s/10s经合法授权的参考音频测试跨语种语音克隆。对于无授权、过期或已撤销授权音色的请求，必须拒绝；独立测负向用例。

## 4. 安全审核和三重核查

- Precision=TP/(TP+FP)，Recall=TP/(TP+FN)，F1=2PR/(P+R)。
- 误拦截率FPR=FP/(FP+TN)，漏检率FNR=FN/(FN+TP)。
- 事实支持率=有对应正确证据的SUPPORTED原子事实数/参与核查原子事实数。
- 引用准确率=正确且相关引用数/所有输出引用数；另报应引用但缺引用的比例。
- 错误检出率=被正确识别的金标准错误数/金标准错误总数。
- 正确拒答率=正确拒绝无充分证据问题数/应拒答的问题数。

对正常业务样本与安全攻击挑战样本分别报告；不得用整体F1代替高风险召回率。若事实无证据支持、Guard超时或独立复核失败，发布门禁必须fail-closed。高风险召回≥99%、误拦≤3%等仅为**待合同确认**的方案目标，不是已实测。

## 5. 端到端性能和容量

RTF=模型处理耗时/处理或生成音频时长。RTF<1只证明特定配置下**单路**处理快于实时，不证明多路吞吐。

统一服务端或客户端单调计时：
- ASR final latency：用户发言结束至终稿文本。
- TTS TTFA：TTS请求接收至首个可播放块。
- End-to-end first audio：用户发言结束至客户端可播放响应音频。
- P95/P99：针对**成功完成**的有效样本统计延迟；失败、超时另报，不得删除请求后夸大通过率。
- 请求失败率=失败有效请求数/全部发起有效请求数。
- 有效并发=满足P95、失败率、无音频卡顿约束的最大持续并发会话数。

规划门槛：ASR单路RTF<1；ASR终稿P95≤800ms；TTS首包P95≤500ms；**预审固定讲解**首声P95≤2500ms；失败率<0.5%。这些是待验证的内部指标。动态知识问答三重核查单独报耗时，不引用预审缓存路径成绩。

压测依次1/2/4/8/16/32路，每档预热后稳态≥15分钟，另执行≥24小时长稳态，覆盖网络断连、打断、缓存过期、GPU OOM和超时。

## 6. 单位成本及门禁

ASR单位成本=ASR分摊费用/成功音频小时；TTS单位成本=服务费用/成功生成音频小时；每对话成本=GPU、CPU、API、存储、网络总运行费用/成功轮次。三年TCO不得同时计入设备采购全价和同一设备折旧。

- 数据违规、数据哈希不符、金标准不完整、Holdout泄漏：INCOMPLETE。
- 指标完整且超出合同错误率、并发、安全标准：FAIL。
- 实测完整且达到约定门槛：PASS。
- 未运行：NOT_RUN。模型崩溃、记录丢失：INCOMPLETE。
- 公开上游数字永不填写到VIS LOCAL实测栏。
