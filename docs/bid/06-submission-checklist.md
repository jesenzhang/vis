## 2. 内容定稿前必须确认

- [ ] 合同准确要求的**语言和方言**、测试条件、录音终端和讲解业务领域。
- [ ] “识别准确率≥95%”的计量方式：每语种的CER/WER、分词与数字规范化、异常与失败样本处理、统计口径。
- [ ] 是否允许云服务/外部API，语音、知识证据、授权音色的安全与出域要求。
- [ ] 是否要求现场演示、纸面基准数据、公开来源截图或第三方检测报告；正式招标文件仅给出“提供评测方案与基准测试数据”，不要额外声称必需某个固定证明形式。
- [ ] 接口最终配额、并发服务水平、鉴权规则与具体集成对象。
- [ ] 相关数据集使用许可与人工采集同意；任何真实说话人样音不得擅自放入公开仓库。

## 3. 实测证据补充顺序

1. 先截图**公开数据集官方页面**：URL、版本、语种和许可，并与公开模型成绩分开。
2. 完成小规模真实ASR演示，收集**输入音频→人工Gold→识别输出→S/D/I/N→CER/WER**证据链；不以工程演示小样本证明95%。
3. 完成每合同语种的封存集报告及同条件可复现运行。
4. 补上授权TTS/声音克隆样音和MOS/SIM/内容错误率，附授权可追溯证据。
5. 补三重核查每层输出、引用证据和拒播案例。
6. 补完整WSS会话、实时字幕、用户打断及GPU资源/延迟/并发截图。
7. 补OpenAPI、鉴权401/403、限流429、第三方联调记录。
8. 完成评委可独立检查的证据索引（run_id、版本、hash、截图路径、原始报告）。

**禁止事项**：不制作虚假的测试系统截图；不把公开数据或第三方结果放进我方实测成绩列；不使用没有音频和Gold的“95%成功率”宣传图；不将规划并发写成真实吞吐。
