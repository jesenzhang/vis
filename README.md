# VIS — Voice Intelligence System

多语种智能语音交互、个性化合成/声音克隆、可信讲解与独立评测工程。当前状态：**方案基线（尚未实现、未完成本地实测）**。

本仓库覆盖本次招标条款第 **4、5、6** 项中的语音范围，不包含整个数据中台的其他建设需求。技术选型：Rust 统一服务入口与编排；Python 语音模型推理、数据处理及评测；独立模型适配器；先本地单路，按实测扩容。

## 阅读顺序

从 [文档导航](docs/README.md) 进入：招标响应 → 模块架构 → 数据集建设 → 测试系统 → 评测指标 → 公开基准 → 接口契约 → 硬件成本 → 实施路线 → 证据清单。

## 必须遵守

- 公开基准仅代表原发布者的测试，不代表 VIS 实测。凡实际未测试，报告状态必须为 `NOT_RUN` / `INCOMPLETE`，不得填 `PASS`。
- 以**合同确定的每个语种**在冻结测试条件下 WER 或 CER ≤ 5% 为目标。当前五语种（zh-CN/en-US/ja-JP/ko-KR/es-ES）只是**规划假设**。
- 数据集必须具备合法来源、人工金标准、说话人隔离、独立封存验收集；禁止提交原始音频、声音授权、密钥、私有答案、模型权重。
- 语音输出必须经过可信发布门禁；缺乏证据不得播报为确定性事实。授权声音克隆需控制范围、撤销和合成标识。
- 本仓库公开接口设计不意味着已完成部署或允许绕过数据/第三方模型许可。
